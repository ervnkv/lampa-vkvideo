# lampa-vkvideo

Плагин VK Видео для [Lampa](https://github.com/yumata/lampa): пункт в меню, каталог полками как на главной и просмотр во встроенном плеере VK.

- «VK Видео» первым пунктом меню. Его можно переместить или скрыть штатным редактором.
- Полки по порядку: история просмотра, рекомендации, вкладки VK Видео («Тренды», «Трансляции», «Детям», «Фильмы и сериалы», «Телеканалы», «Семья и дети») и 11 тематических разделов. «Ещё» открывает вкладку или раздел целиком с бесконечной подгрузкой.
- В каталоге нет роликов, которые VK запрещает смотреть на других сайтах.
- Просмотренные ролики попадают в штатную «Историю» Lampa и открываются оттуда.
- Карточки 16:9 с длительностью, каналом и просмотрами. Идущие эфиры помечены.
- Своя страница просмотра: плеер VK стартует сам, над ним кнопка «Назад», ниже описание, канал, лайки и комментарии (только чтение).
- Работает без входа в VK. Анонимный токен продлевается, поэтому VK узнаёт зрителя между сессиями.

## Установка

В Lampa: «Настройки» → «Расширения» → «Добавить плагин», адрес:

```
https://lampa-vkvideo.vercel.app/vkvideo.js
```

Lampa подключает плагин сразу. Если пункт «VK Видео» не появился в меню, перезапустите Lampa.

Если Lampa раздаётся со своим Content-Security-Policy, разрешите:

- `script-src`: `https://lampa-vkvideo.vercel.app https://api.vkvideo.ru`
- `connect-src`: `https://lampa-vkvideo.vercel.app`
- `img-src`: `https://*.vkuserphoto.ru https://*.userapi.com https://iv.okcdn.ru`
- `frame-src`: `https://vkvideo.ru`

## VK Видео 18+

Отдельный плагин с каталогом [porno-vkvideo.ru](https://porno-vkvideo.ru): полки и темы, «Ещё» открывает все ролики темы, ролик играет на своей странице. В историю Lampa и рекомендации VK ролики не попадают.

```
https://lampa-vkvideo.vercel.app/vkvideo18.js
```

Для CSP дополнительно: `connect-src` — `https://porno-vkvideo.ru`, `frame-src` — `https://yastatic.net`.

## Как устроено

- Каталог, видео и комментарии браузер берёт напрямую у `api.vkvideo.ru` через JSONP.
- Анонимный токен VK браузеру с чужого домена не отдаёт, поэтому его выдаёт функция [`api/token.js`](api/token.js) на Vercel. Она запрашивает у VK фиксированный адрес и передаёт браузер, язык, адрес Lampa и IP клиента, без кук. У каждого клиента свой токен. Он живёт сутки, хранится в Lampa и продлевается через ту же функцию с сохранением анонимной личности VK.
- Можно ли встроить ролик, VK в API не сообщает: это видно только по странице плеера. Её для каждой полки проверяет функция [`api/embed.js`](api/embed.js).
- Видео играет официальный эмбед `vkvideo.ru/video_ext.php`. Ролики 18+ играют через обёртку Яндекса из каталога porno-vkvideo.ru: напрямую VK их на других сайтах не показывает.

Своя копия: форкните репозиторий, импортируйте его в Vercel без настроек сборки и поменяйте `TOKEN_URL` и `EMBED_URL` в `vkvideo.js` на свой домен.

## Ограничения

- Интерфейс только на русском.
- Проверено в Chrome на ПК и в эмуляции iPhone на Lampa 3.3.8. На ТВ и в Android APK может работать, но не проверялось.
- На iPhone Safari может не пустить автостарт со звуком. Тогда нажмите play в плеере.
- Используется `client_id` веб-клиента VK Видео. Если VK его отзовёт, плагин перестанет работать.
- Влияют ли просмотры на рекомендации анонимного зрителя, не подтверждено.
