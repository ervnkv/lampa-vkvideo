# lampa-vkvideo: спецификация v1

Статус: реализовано, проверено на локальном стенде 2026-10-25. Не опубликовано: нет репозитория на GitHub и домена прокси.

## Проблема

В Lampa нет VK Видео. Каталог и страница фильма там построены под TMDB, а стандартная страница видео не умеет играть ролики VK. Нужен отдельный раздел с каталогом VK Видео и своя страница просмотра с эмбедом.

## Решение

Один файл `vkvideo.js` (ES5, без сборки). Его можно добавить в «Расширения» любой Lampa или подключить скриптом. Каталог, видео и комментарии браузер получает напрямую у `api.vkvideo.ru` через JSONP. Для анонимного токена нужен маленький прокси на Coolify: `get_anonym_token` не отдаёт CORS.

Проверка 2026-10-24 (`curl` с `Origin: https://ervnkv.github.io`): ответ `api.vk.com/oauth/get_anonym_token` содержит `Access-Control-Allow-Credentials`, но не содержит `Access-Control-Allow-Origin`. Браузер такой ответ скрипту не отдаст.

## Пользовательские истории

1. Пункт «VK Видео» стоит первым в меню при первой установке. Его можно переместить и скрыть штатным редактором меню.
2. Страница «VK Видео» устроена как главная Lampa: полки с разделами, у каждой полки кнопка «Ещё».
3. «Ещё» открывает сетку раздела с подгрузкой следующих страниц.
4. Клик по видео открывает нашу страницу просмотра, а не стандартную карточку. Ролик стартует сам. Штатное «Назад» Lampa (шапка, нижняя панель, пульт) возвращает в каталог и останавливает видео.
5. Под плеером видны название, просмотры, дата, лайки, канал с аватаром и числом подписчиков, свёрнутое описание.
6. Комментарии только для чтения: по 20 штук, кнопка «Показать ещё», только текст.
7. Каталог работает без входа в VK.

## Решения по реализации

### Репозиторий и поставка

- Отдельный репозиторий `lampa-vkvideo`, лицензия MIT.
- Файл `vkvideo.js` раздаётся из GitHub Pages (ветка `main`, корень): `https://ervnkv.github.io/lampa-vkvideo/vkvideo.js`.
- Проверено на Lampa 3.3.8 (`yumata/lampa`, коммит `02df344`). API взят из исходников `yumata/lampa-source` и официального плагина shots: `Lampa.Component`, `Lampa.Maker`, `Lampa.Activity`, `Lampa.Controller`, `Lampa.Scroll`, `Lampa.Storage`, `Lampa.Menu`.
- Интерфейс только на русском.
- Папка `proxy/` в том же репозитории: `nginx:alpine`, деплой в Coolify из GitHub.
- Повторное подключение скрипта ничего не ломает: второй экземпляр сразу выходит.

### Прокси

- `GET /token` запрашивает `https://api.vk.com/oauth/get_anonym_token?client_id=52461373&scope=video` и отдаёт JSON `{token, expired_at}`.
- Заголовки ответа: `Access-Control-Allow-Origin: *`, `Cache-Control: no-store`. CORS-заголовки и cookie VK вырезаются, `Origin`, `Referer` и `Cookie` клиента в VK не уходят.
- Лимит 10 запросов в минуту с IP (всплеск до 5), сверх него `429`. Реальный IP берётся из `X-Forwarded-For` (его ставит прокси Coolify).
- Остальные пути отдают `404`. Прокси не хранит состояние.

### Токен

- Токен живёт 24 часа (`expired_at` в unix-секундах) и хранится в `Lampa.Storage` (`vkvideo_token`). За минуту до истечения берётся новый.
- Ответ `error_code 1116` (`Anonymous token is invalid`): запросить новый токен и повторить запрос один раз.
- Параллельные запросы ждут один ответ прокси.
- Токен не привязан к IP: выданный сервером работает из браузера с другого адреса (проверено 2026-10-24).

### VK API

Запросы идут JSONP: `https://api.vkvideo.ru/method/<метод>?v=5.282&client_id=52461373&lang=ru&access_token=…&callback=<fn>`.

- JSONP понимают только `catalog.*` и `execute`. `video.get` и `video.getComments` игнорируют `callback` и отдают `application/json` с `nosniff`, браузер такой ответ как скрипт не исполнит (проверено 2026-10-25). Поэтому их плагин вызывает через `execute` с кодом `return API.<метод>(<параметры JSON>);`. Ошибки внутренних методов приходят как обычные (`error_code 15`, `1116`).
- `lang=ru` в query даёт русские названия. JSONP не передаёт заголовки, поэтому язык задаём параметром.
- Главная: `catalog.getVideo` с `url=https://vkvideo.ru/` и `need_blocks=1`. Первый раздел («Все») идёт полкой «Рекомендации», дальше 11 разделов в порядке VK: Интервью и шоу, Политика, Музыка, Путешествия, Авто, Технологии, Еда, Образование, Мода и красота, Здоровье, Культура.
- Полка и страница раздела: `catalog.getSection` с `section_id` и `start_from=<next_from>`, по 20 видео.
- Одно видео (восстановление страницы): `video.get` с `videos=<owner_id>_<id>`, `extended=1`, `fields=photo_100,members_count,verified`.
- Комментарии: `video.getComments` с `owner_id`, `video_id`, `count=20`, `offset`, `sort=desc`, `extended=1`, `fields=photo_100`. «Ещё» показывается, пока загружено меньше `current_level_count`.
- Картинки лежат на `*.vkuserphoto.ru`, `*.userapi.com`, `iv.okcdn.ru` и отдаются с `Access-Control-Allow-Origin: *`.
- Поле `player` видео: `https://vkvideo.ru/video_ext.php?oid=…&id=…&hash=…`.

Поля видео: `likes.count`, `views`, `comments`, `date` (unix-секунды), `duration` (секунды), `live_status` (`started` — идёт эфир), `description`, `image[]`. Канал ищется в `groups` по `id = -owner_id` (`name`, `photo_100`, `members_count`, `verified`), для пользователей в `profiles`. Формат `videos_ids` — `<owner_id>_<id>`, совпадает с ключами `videos`.

### Страница каталога

- Компонент на `Lampa.Maker.make('Main')`. Полки подгружаются порциями по 3: первая при открытии, остальные при прокрутке (штатный `onNext`).
- Карточки 16:9, ширина 21em (на телефоне 18em). На превью длительность или красная плашка «Эфир», под названием (2 строки) канал и просмотры.
- У карточек только модули `Card` и `Callback`: долгое нажатие не предлагает закладки TMDB.
- Превью берётся наименьшее не уже 640 px. Фон Lampa меняется на превью шириной от 320 px, Lampa его размывает.
- «Ещё» у полки открывает раздел с первой страницы, а не с места, где закончилась полка.

### Страница раздела

- `Lampa.Maker.make('Category')` без модуля `Pagination`: бесконечная подгрузка по `next_from`, пока он есть.
- Сетка штатная `cols--4`: 4 колонки на ПК, меньше по брейкпоинтам Lampa, 1 на телефоне.

### Страница видео

- Собственный компонент на `Lampa.Scroll`: на ПК и ТВ прокрутка колесом и пультом, на телефоне нативная.
- Iframe: `player` из API плюс `js_api=1`. `autoplay=1` не добавляем: с ним VK стартует без звука даже после клика (porno-vkvideo, D-038).
- Атрибут `allow`: `autoplay; fullscreen; encrypted-media; picture-in-picture; screen-wake-lock`, плюс `allowfullscreen`.
- Протокол проверен напрямую 2026-10-25: iframe шлёт JSON-строки `{"event": "inited" | "started" | "timeupdate" | …, "state": …, "muted": …}` с origin `https://vkvideo.ru`. На первое `inited` плагин отвечает `postMessage({method: "play"}, "https://vkvideo.ru")`, VK присылает `started`. Автостарт однократный: если iframe перезагрузился, play жмёт пользователь.
- Плеер — первый фокусируемый элемент. OK с пульта ставит паузу или продолжает (по последнему `state`), потому что в iframe пультом не попасть.
- Под плеером название, «N просмотров · дата · ♥ лайки», канал (аватар, галочка, подписчики), описание. Длинное описание (больше 200 символов или 3 строк) свёрнуто до 3 строк и раскрывается по OK или тапу.
- Комментарии: аватар, имя, «N дней назад», текст. Упоминания `[id1|Имя]` показываются как имя. Комментарии без текста (стикеры) пропускаются. Ошибка 801 — «Комментарии закрыты».
- Уход на другой экран шлёт `pause`. При закрытии страницы iframe выгружается сразу, иначе он доигрывает, пока Lampa убирает экран.
- В адрес Lampa попадают только `oid` и `vid`. После перезагрузки страница восстанавливается через `video.get`.

### Меню

- `Lampa.Menu.addButton`, иконка — контурный экран с треугольником в стиле остальных пунктов.
- При первом запуске название добавляется в начало `menu_sort`, дальше порядок и скрытие управляются штатным редактором.

### Конфиги Lampa пользователя (репозиторий `lampa`, вне этого плагина)

- `lampainit.js` подключает `https://ervnkv.github.io/lampa-vkvideo/vkvideo.js`: у пользователя выключены плагины (`plugins_use: false`).
- CSP в `nginx/default.conf.template` расширить:
  - `script-src`: + `https://ervnkv.github.io https://api.vkvideo.ru` (JSONP);
  - `connect-src`: + домен прокси;
  - `img-src`: + `https://*.vkuserphoto.ru https://*.userapi.com https://iv.okcdn.ru`;
  - `frame-src`: сейчас `'none'`, нужно `https://vkvideo.ru`.
- Обновить `AGENTS.md` и `README.md` репозитория `lampa`.

### Платформы

- Гарантируем: Chrome на Windows и PWA на iPhone.
- Android APK и ТВ (Tizen, webOS) — как получится, не проверяем. Код парсится как ES5.

## Тестирование

Автотестов нет, по решению. Ручной smoke-сценарий:

1. Установка: пункт «VK Видео» первый в меню, его можно переместить и скрыть.
2. Главная плагина: полки грузятся, названия русские, картинки видны, полки ниже подгружаются при прокрутке.
3. «Ещё» у полки: открывается сетка, следующая страница подгружается.
4. Клик по видео: открывается страница с эмбедом. В Chrome и на iPhone PWA ролик стартует, звук есть, если браузер разрешил.
5. «Назад»: видео останавливается, возвращаемся в каталог.
6. Под плеером есть название, канал, просмотры, дата, лайки, описание.
7. Комментарии: 20 штук, «Показать ещё» подгружает следующие.
8. Токен: очистить `localStorage`, плагин получает новый. Испортить токен, будет `1116` и повтор.
9. Перезагрузка на странице видео восстанавливает её.
10. Прокси: `curl` на `/token` возвращает 200, `Access-Control-Allow-Origin: *`, `no-store`. Частые запросы дают 429, прочие пути 404.
11. CSP: в консоли на главной и на странице видео нет нарушений, кроме запросов Lampa к cub.

### Результат 2026-10-25

Стенд: Lampa 3.3.8 с сервера, CSP из раздела «Конфиги Lampa», эмуляция `/token`, headless Chrome 1440×900 и эмуляция iPhone 12 Pro (тач, UA iPhone).

- Пройдено: 1 (первым в меню; перемещение и скрытие не проверялись), 2, 3 (20 → 40 карточек), 4 (Chrome headless: `inited` → `play` → `started`, `muted: false`; Chrome запущен с разрешённым автоплеем), 5 (iframe удалён, сообщений от плеера после «Назад» нет), 6, 7 (20 → 40 по тапу на iPhone), 8 (битый токен: один запрос к прокси, каталог загрузился), 9, 10 (образ `proxy/` собран и запущен в Docker на домашнем сервере), 11.
- Не проверено: звук на реальном iPhone и в обычном Chrome без флага автоплея, перемещение и скрытие пункта меню, ТВ и APK.

## Вне v1

- Поиск, страница канала, клипы, эфиры отдельным разделом.
- Вход в VK, история, закладки, подписки.
- Комментарии с ответами, лайками и записью.
- Android APK, Tizen, webOS.

## Риски

- `client_id` 52461373 принадлежит веб-клиенту VK Видео. VK может его отозвать, и плагин перестанет работать.
- `execute` нужен для комментариев и `video.get`. Если VK закроет его для анонимных токенов, пропадут комментарии и восстановление страницы, каталог останется.
- Протокол `js_api` не документирован VK, проверен по факту.
- Звук при автостарте на iPhone не проверен. Safari может запустить без звука или не запустить, тогда пользователь жмёт play в плеере VK.

## Открытые вопросы

1. Домен прокси. Выбирается при деплое в Coolify, затем вписывается в `PROXY_URL`.
2. Конфиги `lampa` (`lampainit.js`, CSP) меняются после деплоя прокси и публикации Pages.
