# lampa-vkvideo: спецификация v2

Статус: v1 в проде с 2026-10-25. v2 (история, витрины, проверка встраивания, продление токена, плагин 18+) — 2026-10-26.

## Проблема

В Lampa нет VK Видео. Каталог и страница фильма там построены под TMDB, а стандартная страница видео не умеет играть ролики VK. Нужен отдельный раздел с каталогом VK Видео и своя страница просмотра с эмбедом.

## Решение

Один файл `vkvideo.js` (ES5, без сборки). Его можно добавить в «Расширения» любой Lampa или подключить скриптом. Каталог, видео и комментарии браузер получает напрямую у `api.vkvideo.ru` через JSONP. Две маленькие функции на Vercel: токен (`get_anonym_token` не отдаёт CORS) и проверка встраивания (VK не сообщает её в API).

Второй файл `vkvideo18.js` — раздел «VK Видео 18+» с каталогом соседнего проекта porno-vkvideo.ru. От `vkvideo.js` не зависит.

Проверка 2026-10-24 (`curl` с `Origin: https://ervnkv.github.io`): ответ `api.vk.com/oauth/get_anonym_token` содержит `Access-Control-Allow-Credentials`, но не содержит `Access-Control-Allow-Origin`. Браузер такой ответ скрипту не отдаст.

## Пользовательские истории

1. Пункт «VK Видео» стоит первым в меню при первой установке. Его можно переместить и скрыть штатным редактором меню.
2. Страница «VK Видео» устроена как главная Lampa: полки, у полки кнопка «Ещё». Порядок: «История просмотра», «Рекомендации», витрины VK («Тренды», «Трансляции», «Детям», «Фильмы и сериалы», «Телеканалы», «Семья и дети»), затем тематические разделы.
3. «Ещё» у истории открывает штатную «Историю» Lampa. У витрины — страницу витрины с её полками. У раздела — сетку с подгрузкой следующих страниц.
4. Просмотренные ролики VK попадают в штатную «Историю» Lampa и открываются оттуда нашей страницей просмотра.
5. В каталоге нет роликов, которые VK не даст посмотреть во встроенном плеере.
6. Клик по видео открывает нашу страницу просмотра, а не стандартную карточку. Ролик стартует сам. Кнопка «Назад» над плеером и штатное «Назад» Lampa (шапка, нижняя панель, пульт) возвращают в каталог и останавливают видео.
7. Под плеером видны название, просмотры, дата, лайки, канал с аватаром и числом подписчиков, свёрнутое описание.
8. Комментарии только для чтения: по 20 штук, кнопка «Показать ещё», только текст.
9. Каталог работает без входа в VK. Анонимная личность VK сохраняется между сессиями, чтобы рекомендации копили историю просмотров.
10. Раздел «VK Видео 18+»: полки и темы porno-vkvideo.ru, «Ещё» открывает все ролики темы, ролик играет на своей странице.

## Решения по реализации

### Репозиторий и поставка

- Репозиторий `ervnkv/lampa-vkvideo`, лицензия MIT.
- Проект Vercel `lampa-vkvideo` из этого репозитория, без сборки. Он раздаёт `https://lampa-vkvideo.vercel.app/vkvideo.js`, `/vkvideo18.js` и функции `/api/token`, `/api/embed`. Каждый пуш в `main` сразу доходит до всех пользователей: Lampa грузит плагин без кэша.
- `vercel.json`: оба скрипта отдаются с `Access-Control-Allow-Origin: *`, потому что «Расширения» Lampa скачивают их XHR-запросом и ищут в тексте `Lampa.`. Корень сайта ведёт на GitHub.
- Проверено на Lampa 3.3.8 (`yumata/lampa`, коммит `02df344`). API взят из исходников `yumata/lampa-source` и официального плагина shots: `Lampa.Component`, `Lampa.Maker`, `Lampa.Activity`, `Lampa.Controller`, `Lampa.Scroll`, `Lampa.Storage`, `Lampa.Menu`, `Lampa.Favorite`, `Lampa.Router`.
- Интерфейс только на русском.
- Повторное подключение скрипта ничего не ломает: второй экземпляр сразу выходит.

### Функция токена (`api/token.js`)

- `GET /api/token` запрашивает фиксированный адрес `https://api.vk.com/oauth/get_anonym_token?client_id=52461373&scope=video` и отдаёт статус и тело VK как есть: `{token, expired_at}`.
- `POST /api/token` с телом-токеном (`text/plain`, простой CORS-запрос без preflight) продлевает его: тот же адрес плюс `anonymous_token=<токен>`. VK выдаёт новый токен с тем же `anonym_id` и сроком на сутки от момента продления, старый продолжает работать (проверено 2026-10-26). Битый токен VK не продлевает (`cant prolong token`), тогда функция выдаёт новый. Тело, не похожее на токен VK, — `400`.
- VK видит клиента так же, как при прямом запросе из браузера: функция передаёт `User-Agent`, `Accept-Language`, `Origin`, `Referer` и `X-Forwarded-For` (Vercel кладёт туда IP клиента). VK выдаёт токен и с `Origin` чужой Lampa (проверено 2026-10-25).
- Куки не передаются. Свои куки VK браузер на чужой домен не шлёт, а `remixstid` из ответа VK ставит на `Domain=vk.com`, и браузер их отбросит. Сторонние куки Safari на iPhone всё равно блокирует.
- Новый токен без продления — новый `anonym_id` (проверено 2026-10-26).
- Ответ: `Access-Control-Allow-Origin: *`, `Cache-Control: no-store`. Другие методы — `405`, VK недоступен — `502`.
- Состояния нет, лимита запросов с IP нет. От злоупотреблений защищают только лимиты тарифа Hobby (1 млн вызовов в месяц).

### Функция проверки встраивания (`api/embed.js`)

- В API VK нет признака, можно ли встроить ролик: поля `catalog.*` и `video.get` (в том числе с `is_embed=true` и `ref_domain`) у рабочих и запрещённых роликов одинаковые (проверено 2026-10-26). VK решает, когда отдаёт страницу плеера `video_ext.php`: вместо плеера приходит заглушка с `embedErrorCallback?.(<код>)`.
- `GET /api/embed?videos=<owner_id>_<id>_<hash>,…` (до 40 штук, `hash` из поля `player`) запрашивает `https://vkvideo.ru/video_ext.php?oid=…&id=…&hash=…&partner_name=lampa` с `Sec-Fetch-Dest: iframe` и без `Referer`, как плеер в Lampa. Ответ `{"blocked": ["<owner_id>_<id>", …]}`.
- Страница с `embedErrorCallback` — запрещён. С `"is_embed":true` — можно. Иначе (антибот-страница VK на ~30 КБ, ошибка сети) — неизвестно, ролик показываем. Пачку из 20 запросов VK примерно в каждом пятом случае отвечает антибот-страницей, поэтому запросы идут по 5 параллельно.
- Известные ответы функция помнит 6 часов в памяти экземпляра. Если неизвестных нет, ответ кэшируется на CDN Vercel на час (`s-maxage=3600`), иначе `no-store`.
- Решение VK одинаковое для запроса из РФ и из США (проверено через VPN 2026-10-26), поэтому IP Vercel не мешает.
- Проверка 2026-10-26 на 132 роликах из рекомендаций и витрин: в браузере в условиях Lampa не играли 17, функция угадала 128 из 132 (4 промаха — антибот-страницы).

Коды ошибок плеера VK (событие `error` в `js_api`), которые встретились: `3` — телеканалы (9 из 20), `6` — права (спорт, трансляции), `9` — контент для взрослых, `11` — разовый случай в «Детям», `4` — сайт открыт по IP без домена. Код `4` в Lampa не возникает: `index.html` Lampa содержит `<meta name="referrer" content="never">`, и VK не видит адрес сайта.

### Токен

- Токен живёт 24 часа (`expired_at` в unix-секундах) и хранится в `Lampa.Storage` (`vkvideo_token`).
- Когда до истечения меньше 23 часов, плагин в фоне продлевает токен через `POST /api/token`, а запрос идёт со старым. Так `anonym_id` живёт, пока Lampa открывают хотя бы раз в сутки. Продлит ли VK уже истёкший токен, не проверено: если нет, функция выдаст новый.
- Ответ `error_code 1116` (`Anonymous token is invalid`): продлить или получить новый токен и повторить запрос один раз.
- Параллельные запросы ждут один ответ функции.
- Токен не привязан к IP: выданный сервером работает из браузера с другого адреса (проверено 2026-10-24). Токен, выданный на IP Vercel, работает в `catalog.getVideo` с адреса в РФ (проверено через другой проект на Vercel 2026-10-25).
- На каждый старт ролика (`started` от плеера) плагин вызывает `video.viewStarted` с этим токеном, как веб-клиент VK. Эмбед засчитывает просмотр своей анонимной сессии, о нашем `anonym_id` VK иначе не узнает. Влияние на рекомендации не подтверждено: за 7 минут после 15 отчётов о кулинарных роликах рекомендации не изменились (2026-10-26).

### VK API

Запросы идут JSONP: `https://api.vkvideo.ru/method/<метод>?v=5.282&client_id=52461373&lang=ru&access_token=…&callback=<fn>`.

- JSONP понимают только `catalog.*` и `execute`. `video.get` и `video.getComments` игнорируют `callback` и отдают `application/json` с `nosniff`, браузер такой ответ как скрипт не исполнит (проверено 2026-10-25). Поэтому их плагин вызывает через `execute` с кодом `return API.<метод>(<параметры JSON>);`. Ошибки внутренних методов приходят как обычные (`error_code 15`, `1116`).
- `lang=ru` в query даёт русские названия. JSONP не передаёт заголовки, поэтому язык задаём параметром.
- Главная: `catalog.getVideo` с `url=https://vkvideo.ru/` и `need_blocks=1`. Первый раздел («Все») идёт полкой «Рекомендации», дальше 11 разделов в порядке VK: Интервью и шоу, Политика, Музыка, Путешествия, Авто, Технологии, Еда, Образование, Мода и красота, Здоровье, Культура.
- Витрины (вкладки сайта VK): `catalog.getVideoShowcase` с `url=https://vkvideo.ru/<витрина>` и `need_blocks=1`. Используются `trends`, `lives`, `for_kids`, `movies_serials`, `tvchannels`, `family`. `catalog.getVideo` с этими адресами отдаёт пустой каталог по умолчанию. Секция с блоками — та, у которой есть `blocks`.
- Полка витрины — блок `data_type: videos`. Название и «Показать все» (`actions[].action.url`) бывают у блока или у предшествующего блока-заголовка (`layout.name: header`). Альбомы («Шоу») и прочие типы блоков пропускаются.
- Следующая порция блоков витрины: `catalog.getSection` с `section_id` секции и `start_from=<section.next_from>` («Детям», «Фильмы и сериалы»).
- Раздел витрины («Показать все»): `catalog.getVideoShowcase` с адресом из действия, дальше `catalog.getSection` с `section_id` полученной секции и `start_from=<next_from блока>`. «Тренды» и «Телеканалы» дальше первой страницы анониму недоступны (`error_code 15`): показываем первую.
- Полка и страница раздела главной: `catalog.getSection` с `section_id` и `start_from=<next_from>`, по 20 видео.
- Одно видео (восстановление страницы, история): `video.get` с `videos=<owner_id>_<id>[,…]`, `extended=1`, `fields=photo_100,members_count,verified`.
- Комментарии: `video.getComments` с `owner_id`, `video_id`, `count=20`, `offset`, `sort=desc`, `extended=1`, `fields=photo_100`. «Ещё» показывается, пока загружено меньше `current_level_count`.
- Просмотр: `video.viewStarted` с `owner_id`, `video_id`, ответ `0`.
- Картинки лежат на `*.vkuserphoto.ru`, `*.userapi.com`, `iv.okcdn.ru` и отдаются с `Access-Control-Allow-Origin: *`.
- Поле `player` видео: `https://vkvideo.ru/video_ext.php?oid=…&id=…&hash=…`.

Поля видео: `likes.count`, `views`, `comments`, `date` (unix-секунды), `duration` (секунды), `live_status` (`started` — идёт эфир), `description`, `image[]`. Канал ищется в `groups` по `id = -owner_id` (`name`, `photo_100`, `members_count`, `verified`), для пользователей в `profiles`. Формат `videos_ids` — `<owner_id>_<id>`, совпадает с ключами `videos`.

### Страница каталога

- Компонент на `Lampa.Maker.make('Main')`. При открытии: история, рекомендации и две первые витрины. Остальные витрины и разделы подгружаются по 3 при прокрутке (штатный `onNext`).
- Каждую полку перед показом проверяет `/api/embed`. Запрещённые ролики выкидываются, пустая полка не показывается. Если функция не ответила за 8 секунд, полка показывается без проверки.
- Полка витрины на главной — до 20 роликов: по очереди из всех её блоков. «Ещё» ведёт на страницу витрины, если блоков несколько, иначе сразу в раздел блока. У «Телеканалов» раздела нет, «Ещё» нет.
- Карточки 16:9, ширина 21em (на телефоне 18em). На превью длительность или красная плашка «Эфир», под названием (2 строки) канал и просмотры.
- У карточек только модули `Card` и `Callback`: долгое нажатие не предлагает закладки TMDB.
- Превью берётся наименьшее не уже 640 px. Фон Lampa меняется на превью шириной от 320 px, Lampa его размывает.
- «Ещё» у полки раздела открывает раздел с первой страницы, а не с места, где закончилась полка.

### История просмотра

- При открытии страницы видео ролик добавляется в штатную историю Lampa: `Lampa.Favorite.add('history', card, 100)`, как это делает плеер Lampa. Карточка: `id` = `<owner_id>_<id>`, `source: 'vkvideo'`, `title`, `img` (превью), `background_image`. Lampa хранит из карточки только свой список полей, поэтому остальное берётся заново.
- Роликов VK в истории не больше 20: лишние удаляются. Lampa держит в истории 100 записей на всё, и ролики не должны вытеснить фильмы и сериалы.
- Полка «История просмотра» — ролики VK из истории Lampa в её порядке. Данные берутся одним `video.get`, проверка встраивания та же. Удаление из истории Lampa убирает ролик и с полки.
- Карточки истории Lampa открывает через `Lampa.Router.call('full', card)`. Плагин перехватывает этот вызов для `source: 'vkvideo'` и открывает свою страницу видео по `owner_id` и `id`.
- Ролик VK — не сериал, поэтому Lampa показывает его и в строке «Просмотренные» на странице «Фильмы». Открывается он и оттуда нашей страницей.

### Страница витрины

- `Lampa.Maker.make('Main')`: полки — блоки витрины с видео, у каждой «Ещё» на её раздел. Следующие блоки подгружаются при прокрутке, если у секции есть `next_from`.

### Страница раздела

- `Lampa.Maker.make('Category')` без модуля `Pagination`: бесконечная подгрузка по `next_from`, пока он есть.
- Открывается по `section_id` (разделы главной) или по адресу раздела витрины. Ролики берутся из всех блоков с видео в ответе.
- Сетка штатная `cols--4`: 4 колонки на ПК, меньше по брейкпоинтам Lampa, 1 на телефоне.

### Страница видео

- Собственный компонент на `Lampa.Scroll`: на ПК и ТВ прокрутка колесом и пультом, на телефоне нативная.
- Над плеером кнопка «Назад» (штатная `simple-button` со спрайтом `sprite-backward`). Она нужна на ПК: после клика по плееру клавиатура остаётся в iframe, и Esc с Backspace до Lampa не доходят. На ТВ первым фокус получает плеер.
- Iframe: `player` из API плюс `partner_name=lampa&js_api=1`. `partner_name` помечает эмбед как встроенный в Lampa и не меняет, разрешит ли VK его показать (проверено 2026-10-26).
- Автоплей — командой `play` через postMessage. `autoplay=1` не добавляем: проверка в Lampa 2026-10-26 (Chrome, политика автоплея по умолчанию, ПК и эмуляция iPhone) показала, что с ним VK всегда стартует без звука, даже после клика. С `play` после клика по карточке ролик стартует со звуком. Без жеста пользователя (страница восстановлена после перезагрузки) VK присылает `autoplaySoundProhibited` и сам стартует без звука.
- Атрибут `allow`: `autoplay; fullscreen; encrypted-media; picture-in-picture; screen-wake-lock`, плюс `allowfullscreen`.
- Протокол проверен напрямую 2026-10-25: iframe шлёт JSON-строки `{"event": "inited" | "started" | "timeupdate" | "error" | …, "state": …, "muted": …}` с origin `https://vkvideo.ru`. На первое `inited` плагин отвечает `postMessage({method: "play"}, "https://vkvideo.ru")`, VK присылает `started`. Автостарт однократный: если iframe перезагрузился, play жмёт пользователь.
- Если плеер прислал `error` (VK не дал встроить ролик, а функция этого не поймала), ролик запоминается до перезагрузки Lampa и больше не попадает в полки. Плеер VK сам показывает причину и ссылку «Открыть ВКонтакте».
- Плеер — первый фокусируемый элемент после «Назад». OK с пульта ставит паузу или продолжает (по последнему `state`), потому что в iframe пультом не попасть.
- Под плеером название, «N просмотров · дата · ♥ лайки», канал (аватар, галочка, подписчики), описание. Длинное описание (больше 200 символов или 3 строк) свёрнуто до 3 строк и раскрывается по OK или тапу.
- Комментарии: аватар, имя, «N дней назад», текст. Упоминания `[id1|Имя]` показываются как имя. Комментарии без текста (стикеры) пропускаются. Ошибка 801 — «Комментарии закрыты».
- Уход на другой экран шлёт `pause`. При закрытии страницы iframe выгружается сразу, иначе он доигрывает, пока Lampa убирает экран.
- В адрес Lampa попадают только `oid` и `vid`. После перезагрузки страница восстанавливается через `video.get`.

### Меню

- `Lampa.Menu.addButton`, иконка — контурный экран с треугольником в стиле остальных пунктов.
- При первом запуске название добавляется в начало `menu_sort`, дальше порядок и скрытие управляются штатным редактором.

### VK Видео 18+ (`vkvideo18.js`)

- Каталог: `GET https://porno-vkvideo.ru/api/dr-video/catalog` (CORS `*`, ~900 КБ): 40 полок по 10 роликов, 37 тем, ~770 роликов с `title`, `imageUrl`, `author`, `description`, `categoryIds`, `presentation: portrait` у клипов и `playback.url`. Ответ хранится в памяти 30 минут.
- Полки идут в порядке каталога, подгружаются по 6 при прокрутке. «Ещё»: у темы — все ролики темы из каталога, у «Новинок» — все ролики, у «Клипов» — все вертикальные. У «Популярного за неделю» в каталоге только его 10 роликов, «Ещё» нет. Сетка листается по 20 локально.
- Ролик играет обёртка Яндекса из `playback.url` (`yastatic.net/video-player/…/vk.html#html=<iframe vkvideo.ru…>`). Прямой эмбед VK для этих роликов не играет: «Алгоритмы определили, что видео может содержать контент для взрослых, — такие ролики не получится смотреть на внешних сайтах» (код `9`, проверено 2026-10-26).
- Во внутреннем эмбеде VK плагин меняет `partner_name=pvkv` на `partner_name=lampa` (в адресе обёртки он закодирован: `partner_name%3D…`). Обёртка с ним играет (проверено 2026-10-26).
- Протокол обёртки (проверен 2026-10-26): события VK с префиксом `sandbox:` (`sandbox:inited`, `sandbox:started`, `sandbox:paused`, поле `state`) с origin `https://yastatic.net`, команды `{method: "sandbox:play" | "sandbox:pause"}`. `sandbox:inited` приходит дважды: от плеера VK (с `state`) и от самой обёртки (без `state`). Свой иногда приходит первым, раньше готовности плеера, и `play` на него теряется. Поэтому автостарт однократный и только по `sandbox:inited` с `state`. После клика ролик стартует со звуком, без жеста обёртка сама стартует без звука.
- Страница ролика: «Назад», плеер, название, автор, описание. Комментариев, VK API и токена нет. Фон Lampa не меняется: большие превью она почти не размывает. Ролики 18+ не попадают в историю Lampa и не отчитываются на токен VK, чтобы не влиять на рекомендации основного раздела.
- В адрес Lampa попадает только `id` ролика. После перезагрузки страница находит его в каталоге.
- Пункт меню «VK Видео 18+» добавляется в конец меню.

## Тестирование

Автотестов нет, по решению. Ручной smoke-сценарий:

1. Установка: пункт «VK Видео» первый в меню, его можно переместить и скрыть.
2. Главная плагина: история первой, за ней рекомендации и витрины, полки ниже подгружаются при прокрутке, названия русские, картинки видны.
3. «Ещё»: у истории открывается «История» Lampa, у витрины — её полки, у раздела — сетка с подгрузкой.
4. Проверка встраивания: в полках нет роликов, на которых плеер VK показывает ошибку.
5. Клик по видео: открывается страница с эмбедом. В Chrome и на iPhone PWA ролик стартует, звук есть, если браузер разрешил.
6. «Назад» (кнопка над плеером и штатное): видео останавливается, возвращаемся в каталог.
7. Под плеером есть название, канал, просмотры, дата, лайки, описание. Комментарии: 20 штук, «Показать ещё» подгружает следующие.
8. История: просмотренный ролик первым на полке «История просмотра» и в «Истории» Lampa, оттуда открывается страница видео.
9. Токен: очистить `localStorage`, плагин получает новый. Испортить токен, будет `1116` и повтор. Токен старше часа продлевается с тем же `anonym_id`.
10. Перезагрузка на странице видео восстанавливает её.
11. Функции: `/api/token` GET и POST отдают токен, `/api/embed` отличает запрещённый ролик от рабочего, CORS `*`.
12. 18+: пункт меню, полки, «Ещё» темы, ролик играет в обёртке.
13. CSP: в консоли нет нарушений, кроме запросов Lampa к cub.

## Риски

- `client_id` 52461373 принадлежит веб-клиенту VK Видео. VK может его отозвать, и плагин перестанет работать.
- `execute` нужен для комментариев, истории и `video.get`. Если VK закроет его для анонимных токенов, пропадут комментарии, история и восстановление страницы, каталог останется.
- Протокол `js_api` и разметка страницы плеера (`embedErrorCallback`, `"is_embed":true`) не документированы VK, проверены по факту. Если разметка изменится, функция перестанет находить запрещённые ролики, и они снова появятся в полках.
- Антибот VK на `video_ext.php` может начать отвечать заглушкой на все запросы с IP Vercel. Тогда проверка тихо выключится.
- Звук при автостарте на iPhone не проверен. Safari может запустить без звука или не запустить, тогда пользователь жмёт play в плеере VK.
- `/api/token` и `/api/embed` открыты всем, лимита с IP нет. Если кто-то начнёт их массово дёргать, Vercel остановит проект по лимитам Hobby или VK ограничит IP Vercel, и плагин перестанет работать у всех.
- Код с Vercel выполняется в каждой Lampa, где стоит плагин, с доступом к её `localStorage`. Доступ к GitHub и Vercel нужно беречь (2FA).
- 18+ зависит от porno-vkvideo.ru и версии обёртки Яндекса в `playback.url`. Поломку обёртки чинит porno-vkvideo, плагин берёт адрес из каталога.
