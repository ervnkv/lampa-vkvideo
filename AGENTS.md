# lampa-vkvideo

- Источник истины по поведению: `docs/SPEC.md`. Сначала меняем спеку, потом код.
- Плагин — один файл `vkvideo.js`: ES5, без сборки и npm. Проверка синтаксиса: парсер с `ecmaVersion: 5`.
- `api/token.js` (функция Vercel) только выдаёт анонимный токен VK: адрес VK фиксирован, параметры клиента не используются, куки не передаются. Проверка локально: запустить обработчик в `http.createServer` из Node.
- Vercel деплоит `main` без сборки, и пуш сразу доходит до всех пользователей плагина. Пушить в `main` только проверенное.
- JSONP у `api.vkvideo.ru` понимают только `catalog.*` и `execute`, остальные методы вызываются через `execute`.
- Факты о VK проверять по ответам API, а не по памяти. Ответ JSONP проверять на обёртку `callback(...)`, а не снимать её регуляркой.
- Автотестов нет. Проверка — smoke-сценарий из `docs/SPEC.md` в настоящей Lampa (сборка `yumata/lampa`) с прод-CSP.
- После смены поведения обновить `docs/SPEC.md` и `README.md`.
