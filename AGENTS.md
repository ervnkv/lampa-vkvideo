# lampa-vkvideo

- Источник истины по поведению: `docs/SPEC.md`. Сначала меняем спеку, потом код.
- Плагины — по одному файлу: `vkvideo.js` (VK Видео) и `vkvideo18.js` (VK Видео 18+ из porno-vkvideo.ru, от первого не зависит). ES5, без сборки и npm. Проверка синтаксиса: парсер с `ecmaVersion: 5`.
- Функции Vercel ходят только на фиксированные адреса VK, кук не передают, параметры клиента проверяют по формату: `api/token.js` выдаёт анонимный токен VK и продлевает присланный, `api/embed.js` по странице плеера проверяет, можно ли встроить ролики. Проверка локально: запустить обработчик в `http.createServer` из Node.
- Vercel деплоит `main` без сборки, и пуш сразу доходит до всех пользователей плагина. Пушить в `main` только проверенное.
- JSONP у `api.vkvideo.ru` понимают только `catalog.*` и `execute`, остальные методы вызываются через `execute`.
- Факты о VK проверять по ответам API, а не по памяти. Ответ JSONP проверять на обёртку `callback(...)`, а не снимать её регуляркой.
- Автотестов нет. Проверка — smoke-сценарий из `docs/SPEC.md` в настоящей Lampa (сборка `yumata/lampa`) с прод-CSP. Плеер проверять в Chrome с `--mute-audio`.
- После смены поведения обновить `docs/SPEC.md` и `README.md`.
